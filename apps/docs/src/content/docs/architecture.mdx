## The one-protocol principle

Every face talks to the core through the same messages. Desktop and
mobile adapt a single Tauri `rpc` command; the extension speaks native
messaging through the host; all three terminate in `castellan-dispatch`.
The app shells contain no operation match. A feature that bypasses the
protocol is a design error by definition—see [the protocol](/castellan/protocol/).

## One autofill request, end to end

1. The content script reports the page origin to the background service
   worker.
2. The extension pre-filters using the **WASM build** of
   `origin_matches` — the same Rust function, compiled to a different
   target.
3. The background sends `get_entries { origin }` through the client.
4. The app **re-validates the origin authoritatively**, projects
   matching entries (metadata and flags only), and answers.
5. The fill happens on the user's gesture. The extension holds one
   password for the blink it takes to type it — never the vault.

## The WASM boundary

WASM gets **pure functions over data the extension already has**:
origin matching, otpauth validation. Native keeps everything that touches
the vault, the disk, the socket, or a secret. The moment TOTP seeds move
into the WASM face to save a round-trip, the containment contract that
bounds extension compromise dies — so the boundary stays where it is,
and offline computation in the browser would be a designed,
sealed-cache decision, not a convenience.

## The codegen flow

The `rpc_contract!` invocation in `crates/protocol` declares every request,
its correlated result and the faces that expose it. `castellan-xtask`
regenerates wire types, the WASM result projection, browser-specific native
host manifests, and committed `DesktopClient`, `MobileClient` and
`WebExtensionClient` classes. Shared operations appear in each selected
class while domain-only operations do not leak to other faces. All generated
clients extend `RpcClient` in `@castellan/core`, which owns request ids,
envelopes, result checking and errors. CI runs `pixi run codegen-check`, so a
changed, missing, or newly untracked generated file fails before typecheck.
