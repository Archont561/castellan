Castellan is a local-first, offline password manager built around one idea:
**the vault is a file you own.** A KDBX database on your disk, opened with
your master password, projected to three faces — a desktop app, a mobile
app, and **Fob**, the browser companion — through one protocol with one
implementation of every rule.

There are no accounts, no cloud, no subscription, and no telemetry. Where
Bitwarden has a server, Castellan has a **device mesh**: your devices find
each other on the LAN, pair by QR code, and sync the vault directly.

  <div>
    ### [:icon{name="lucide:network"} The device mesh](/castellan/architecture/)

    ### [:icon{name="lucide:file-code-2"} One implementation](/castellan/protocol/)

## The promise this repo is built around

One vault file, three faces that render it, one protocol they all speak,
and one implementation of every security rule — in the trusted process,
never in the browser. Everything else is a feature; those four are the
product.

:::note[Status]
Castellan is pre-release: the monorepo, protocol, and core crates are
built and validated; the user-facing milestones are sequenced in the
[roadmap](/castellan/roadmap/). The docs you are reading cover the
architecture and the repository as they exist today.
:::
