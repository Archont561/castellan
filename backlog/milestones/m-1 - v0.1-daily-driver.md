## Description

The smallest Castellan that replaces an existing password manager for one real user:
unlock a KDBX vault, search it, autofill in the browser, generate and fill TOTP codes,
generate passphrases, auto-lock sensibly, sit in the tray. Ship criteria: the author uses
it as their only password manager for two weeks (the dogfood gate).
