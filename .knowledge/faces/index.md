# Faces

The delivery surfaces: three today (desktop, mobile, extension), the CLI
planned. All render the same core through the same protocol.

* [Desktop face](desktop.md) - Tauri + SvelteKit static; the primary experience
* [Mobile face](mobile.md) - Android/iOS with credential-provider shells
* [Extension face — Fob](extension.md) - the browser companion; strictest limits
